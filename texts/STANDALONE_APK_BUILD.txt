STANDALONE APK BUILD GUIDE
==========================

This guide includes both cloud and local build options.

IMPORTANT PLATFORM NOTE
-----------------------

- EAS local Android builds (`eas build --platform android --local`) require macOS or Linux.
- On Windows, use local Gradle build after Android Studio setup.


WINDOWS LOCAL APK BUILD (NO CLOUD QUOTA)
----------------------------------------

1. Install Android Studio (default SDK location is fine)

2. In Android Studio SDK Manager, install:
   - Android SDK Platform 35
   - Android SDK Build-Tools 35.0.0
   - Android SDK Command-line Tools (latest)
   - Android SDK Platform-Tools

3. Install JDK 17

4. Create `android/local.properties` with your SDK path:
   sdk.dir=C:\\Users\\<your-username>\\AppData\\Local\\Android\\Sdk

5. Build local release APK:
   cd android
   gradlew.bat assembleRelease

6. Output APK path:
   app\\build\\outputs\\apk\\release\\app-release.apk

7. Install on device (USB debugging enabled):
   adb install -r app\\build\\outputs\\apk\\release\\app-release.apk


PREVIEW BUILD (CLOUD, FOR TESTING)
----------------------------------

1. Build preview APK for Android:
   eas build --profile preview --platform android

2. Wait for build to complete (~10-15 minutes)

3. Download APK from the link provided

4. Install on your device and run directly


PRODUCTION BUILD (CLOUD, FINAL RELEASE)
---------------------------------------

1. Build production AAB for Android:
   eas build --profile production --platform android

2. Wait for build to complete

3. Download AAB from the link provided

4. Submit to Google Play Store or convert to APK


KEY DIFFERENCES
---------------

Local Gradle Build (Windows):
- Fully local, no cloud quota
- Requires Android SDK + JDK setup
- Output is APK directly

Preview/Production EAS Cloud Build:
- Runs on Expo cloud servers
- No local Android SDK needed
- Preview can output APK; production outputs AAB by default


QUICK COMMANDS
--------------

Windows local APK:  cd android && gradlew.bat assembleRelease
Local APK path:     android\\app\\build\\outputs\\apk\\release\\app-release.apk
Preview APK:        eas build --profile preview --platform android
Production AAB:     eas build --profile production --platform android
Check builds:       eas build:list
